Input Widgets & Forms

A. Pendahuluan

Flutter merupakan framework open-source yang digunakan untuk mengembangkan aplikasi multiplatform dengan menggunakan bahasa pemrograman Dart. Dalam pengembangan antarmuka aplikasi Flutter, seluruh elemen tampilan dibangun menggunakan konsep widget. Form merupakan widget yang digunakan untuk mengelompokkan beberapa komponen input dalam satu kesatuan sehingga proses pengelolaan dan validasi data dapat dilakukan dengan lebih terstruktur.

Salah satu widget yang dapat digunakan di dalam Form adalah TextFormField, yang berfungsi untuk menerima input berupa teks maupun angka dari pengguna. TextEditingController digunakan untuk mengontrol dan mengambil nilai yang dimasukkan pada TextFormField. Selain itu, DropdownButtonFormField dapat digunakan untuk menyediakan pilihan data dalam bentuk dropdown, sedangkan ElevatedButton dapat digunakan untuk menjalankan suatu proses setelah pengguna mengisi form.

Dalam pengolahan input, validasi diperlukan untuk memastikan data yang diberikan pengguna sesuai dengan ketentuan yang telah ditentukan. Flutter menyediakan properti validator pada widget form untuk memeriksa nilai input, misalnya memastikan data tidak kosong atau memastikan nominal berupa angka yang valid. Pengelolaan perubahan data pada widget juga dapat dilakukan menggunakan StatefulWidget dan setState(), terutama ketika terdapat data yang berubah akibat interaksi pengguna.

B. Tujuan

  1. Memahami dan menerapkan pengambilan teks dari pengguna menggunakan controller.
  2. Memahami dan menerapkan widget dropdown statis.
  3. Memahami dan menerapkan validasi input untuk mencegah data kosong atau format yang salah.

C. Langkah Kerja Praktikum

a) Class add_transaction_screen.dart

  1. Buat file dart baru dengan nama add_transaction_screen.dart.
  2. Tambahkan Widget Utama Form Transaksi.

    Class AddTransactionScreen digunakan sebagai halaman untuk menambahkan transaksi baru. Class ini menerapkan StatefulWidget karena terdapat data yang dapat berubah berdasarkan interaksi pengguna, seperti pilihan kategori pada dropdown.

  3. Tambahkan class AddTransactionScreenState.

    Class AddTransactionScreenState digunakan untuk mengelola state dan data yang terdapat pada halaman form transaksi. Pada class ini dibuat GlobalKey<FormState> dengan nama _formKey yang digunakan untuk mengontrol form dan menjalankan proses validasi.

    Selain itu, digunakan TextEditingController untuk mengambil nilai yang dimasukkan pengguna pada input judul transaksi dan nominal transaksi. State untuk dropdown disimpan pada variabel _selectedCategory, sedangkan daftar pilihan kategori disimpan pada variabel _categories.

  4. Tambahkan method dispose().

    Method dispose() digunakan untuk membersihkan controller ketika halaman ditutup. Controller yang digunakan pada form harus dihentikan menggunakan method dispose() agar resource yang digunakan tidak terus tersimpan dan dapat mencegah terjadinya memory leak.

  5. Tambahkan method build() dan struktur halaman.

    Method build() digunakan untuk membangun tampilan halaman form transaksi. Widget Scaffold digunakan sebagai struktur dasar halaman yang terdiri dari AppBar dan body. AppBar digunakan untuk menampilkan judul "Catat Transaksi Baru".

    Bagian body menggunakan SingleChildScrollView agar seluruh isi form dapat digulir ketika ukuran konten lebih panjang daripada ukuran layar, terutama ketika keyboard muncul. Di dalamnya terdapat widget Form yang menggunakan _formKey sebagai key untuk proses validasi.

    Widget Column digunakan untuk menyusun seluruh komponen input secara vertikal, sedangkan crossAxisAlignment: CrossAxisAlignment.stretch digunakan agar komponen memenuhi lebar yang tersedia.

  6. Tambahkan input Judul Transaksi.

    Input judul transaksi menggunakan widget TextFormField. Nilai input dikontrol menggunakan _titleController. Input dilengkapi dengan InputDecoration berupa label "Judul Transaksi", OutlineInputBorder, dan ikon title.

    Properti validator digunakan untuk memastikan bahwa judul transaksi tidak kosong. Apabila pengguna tidak memasukkan judul transaksi, sistem akan menampilkan pesan "Judul transaksi tidak boleh kosong".

  7. Tambahkan input Nominal Transaksi.

    Input nominal transaksi juga menggunakan TextFormField dengan controller _amountController. Properti keyboardType: TextInputType.number digunakan agar keyboard yang ditampilkan kepada pengguna berupa keyboard angka.

    Validasi dilakukan untuk memastikan nominal tidak kosong dan harus berupa angka bulat yang valid. Fungsi int.tryParse() digunakan untuk memeriksa apakah nilai yang dimasukkan dapat dikonversi menjadi bilangan bulat.

  8. Tambahkan DropdownButtonFormField untuk kategori transaksi.

    Widget DropdownButtonFormField digunakan untuk memberikan pilihan kategori transaksi kepada pengguna. Kategori yang tersedia terdiri dari Makanan, Transportasi, Hiburan, dan Lainnya. Nilai awal yang dipilih adalah kategori "Makanan".

    Setiap kategori dibuat menjadi DropdownMenuItem menggunakan fungsi map(). Ketika pengguna memilih kategori baru, method setState() digunakan untuk memperbarui nilai _selectedCategory.

  9. Tambahkan tombol Simpan Transaksi.

    Tombol simpan menggunakan widget ElevatedButton. Tombol diberi warna deep purple dan teks berwarna putih. Ketika tombol ditekan, program menjalankan proses validasi menggunakan _formKey.currentState!.validate().

    Jika seluruh input telah memenuhi aturan validasi, sistem akan menampilkan SnackBar yang berisi informasi transaksi yang berhasil disimpan, yaitu judul transaksi dan nominal transaksi.

    10. b) Class main.dart

    1. Buat file main.dart.
    2. Import package Flutter dan file form input.

      Package flutter/material.dart digunakan untuk menyediakan komponen Material Design pada aplikasi Flutter. Selain itu, file add_transaction_screen.dart di-import agar class AddTransactionScreen dapat digunakan sebagai halaman utama aplikasi.

    3. Tambahkan fungsi main().

      Fungsi main() merupakan titik awal eksekusi aplikasi Flutter. Fungsi ini menggunakan runApp() untuk menjalankan widget utama aplikasi, yaitu MyApp.

    4. Tambahkan class MyApp.

      Class MyApp merupakan widget utama aplikasi dan menerapkan StatelessWidget. Widget ini digunakan untuk mengatur konfigurasi utama aplikasi yang tidak membutuhkan perubahan state.

    5. Output program.

    D. Tugas

    Menambahkan Input Tanggal Transaksi sebelum tombol Simpan.

    1. Tambahkan _dateController.

      Ditambahkan TextEditingController dengan nama _dateController. Controller ini digunakan untuk mengambil dan menyimpan tanggal yang dipilih pengguna serta menampilkan hasil tanggal tersebut pada TextFormField.

    2. Tambahkan input Tanggal Transaksi sebelum tombol Simpan.

      Input tanggal menggunakan widget TextFormField dengan controller _dateController. Properti readOnly: true digunakan agar pengguna tidak memasukkan tanggal secara manual melalui keyboard.

      Input dilengkapi dengan label "Tanggal Transaksi", garis tepi menggunakan OutlineInputBorder, dan ikon kalender menggunakan Icons.calendar_today.

    3. Tambahkan fungsi showDatePicker().

      Ketika input tanggal ditekan, fungsi showDatePicker() dijalankan untuk menampilkan kalender kepada pengguna. Tanggal awal menggunakan tanggal saat ini melalui DateTime.now(), sedangkan tanggal yang dapat dipilih dibatasi mulai tahun 2000 hingga tahun 2100.

    4. Tampilkan tanggal yang telah dipilih.

      Setelah pengguna memilih tanggal, program memeriksa apakah nilai pickedDate tidak bernilai null. Jika tanggal telah dipilih, nilai tanggal dimasukkan ke dalam _dateController.text dengan format DD/MM/YYYY.

      Method setState() digunakan agar perubahan data tanggal dapat diperbarui pada tampilan aplikasi.

    5. Tambahkan validasi tanggal.

      Validasi pada input tanggal digunakan untuk memastikan pengguna telah memilih tanggal transaksi. Jika input tanggal masih kosong, sistem akan menampilkan pesan "Tanggal transaksi wajib diisi".

    6. Output program.

    E. Kesimpulan

    Berdasarkan praktikum yang telah dilakukan, dapat dipahami bahwa Form digunakan untuk mengelompokkan beberapa komponen input dalam satu kesatuan sehingga proses pengelolaan dan validasi data dapat dilakukan dengan lebih terstruktur. Praktikum ini menerapkan TextFormField, TextEditingController, DropdownButtonFormField, dan ElevatedButton untuk menerima dan mengelola data transaksi. Selain itu, validasi input digunakan untuk mencegah data kosong atau format yang salah. Pada tugas tambahan juga diterapkan showDatePicker() untuk memilih tanggal transaksi sehingga pengguna dapat memasukkan data tanggal melalui kalender secara lebih terstruktur.
