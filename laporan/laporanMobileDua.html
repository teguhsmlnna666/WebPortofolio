Laporan Praktikum Aplikasi Mobile - Pekan 2

Pengenalan Widgets & Layouting, Styling

A. Pendahuluan

Flutter merupakan framework open-source yang digunakan dalam pengembangan aplikasi yang dapat dijalankan di berbagai platform. Dalam Flutter, tampilan aplikasi dibangun menggunakan konsep widget, yaitu komponen dasar yang digunakan untuk membentuk struktur, tampilan, dan interaksi pada aplikasi. Widget dapat disusun secara hierarkis sehingga setiap bagian antarmuka dapat dibuat secara terstruktur dan dapat digunakan kembali.

Berdasarkan penggunaannya widget pada Flutter dapat dibedakan menjadi StatelessWidget dan StatefulWidget. StatelessWidget digunakan untuk menampilkan komponen yang bersifat statis tetap dan tidak memiliki perubahan state selama aplikasi berjalan, sedangkan StatefulWidget digunakan ketika tampilan atau data suatu komponen dapat berubah akibat interaksi pengguna. StatefulWidget memiliki state yang dapat diperbarui menggunakan setState() sehingga perubahan tersebut dapat ditampilkan kembali pada antarmuka aplikasi.

Selain widget dasar Flutter juga menyediakan berbagai widget untuk mengatur tata letak tampilan aplikasi. Row digunakan untuk menyusun beberapa widget secara horizontal, sedangkan Column digunakan untuk menyusun widget secara vertikal. Widget Padding dan SizedBox dapat digunakan untuk mengatur jarak antar-komponen, sedangkan Container digunakan untuk membungkus dan mengatur tampilan suatu widget, seperti warna, padding, dan bentuk. Widget Card dapat digunakan untuk membuat komponen berbentuk kartu, sedangkan ListTile menyediakan struktur yang praktis untuk menampilkan informasi dalam bentuk daftar dengan bagian leading, title, subtitle, dan trailing.

B. Tujuan

  1. Memahami kerangka dasar tampilan aplikasi Flutter.
  2. Mampu membedakan penggunaan StatelessWidget dan StatefulWidget.
  3. Menerapkan widget Row untuk deretan tombol aksi.
  4. Menerapkan widget Column untuk daftar transaksi.

C. Langkah Kerja Praktikum

a) Modul 1 - Pengenalan Widgets Stateless, Stateful, & Manajemen State Dasar

  1. Buat file dart baru dengan nama main.
  2. Import package flutter.
  3. Tambahkan fungsi main().

    Fungsi main() ini digunakan untuk menjalankan program flutter.

  4. Tambahkan class MyApp sebagai widget utama aplikasi.

    Pada class ini aplikasi dibuat menggunakan MaterialApp yang berfungsi sebagai dasar struktur aplikasi Flutter dengan pengaturan judul, tema, dan halaman awal. Widget MyApp menerapkan class StatelessWidget karena konfigurasi utama aplikasi tidak ada perubahan setelah aplikasi berjalan.

  5. Tambahkan class DashboardScreen sebagai halaman utama aplikasi.

    Pada class halaman utama menggunakan Scaffold untuk membentuk struktur dasar aplikasi yang terdiri dari AppBar dan body. Konten utama aplikasi disusun secara vertikal menggunakan Column dan Padding untuk mengatur jarak dari tepi layar serta SizedBox untuk memberikan jarak antar-widget.

  6. Tambahkan class GreetingWidget.

    Pada class GreetingWidget menerapkan class StatelessWidget untuk menampilkan informasi sapaan pengguna yang bersifat statis atau tidak ada perubahan data setelah aplikasi dijalankan. Struktur utamanya menggunakan Row untuk menyusun elemen secara horizontal. Di dalamnya terdapat CircleAvatar yang digunakan untuk menampilkan ikon profil berbentuk lingkaran, backgroundColor berwarna biru dan Icon(Icons.person) untuk menampilkan ikon pengguna berwarna putih. Kemudian Column digunakan untuk menyusun dua teks secara vertikal.

  7. Tambahkan class BalanceCardWidget.

    Class BalanceCardWidget menerapkan StatefulWidget karena tampilan saldo dapat berubah ketika pengguna melakukan interaksi. Widget ini memiliki objek state _BalanceCardWidgetState yang digunakan untuk menyimpan dan mengelola perubahan data pada widget. Variabel _isBalanceVisible digunakan untuk menentukan apakah saldo sedang ditampilkan atau disembunyikan. Fungsi _toggleVisibility() digunakan untuk mengubah kondisi tampilan saldo.

    Widget Card digunakan untuk membuat tampilan kartu saldo. Pada bagian atas card menggunakan Row untuk menempatkan teks "Saldo Utama" dan tombol ikon mata dalam satu baris, jika saldo terlihat ikon yang digunakan adalah visibility, sedangkan jika saldo disembunyikan, ikon berubah menjadi visibility_off, dan ketika tombol ditekan, onPressed: _toggleVisibility akan menjalankan fungsi _toggleVisibility(). Nominal saldo akan ditampilkan berdasarkan kondisi pada _isBalanceVisible.

  8. Output program.

b) Modul 2 - Layouting & Styling (Row, Column, Container, dan ListTile)

  1. Perbarui class DashboardScreen.

    Pada class DashboardScreen menggunakan SingleChildScrollView agar seluruh isi halaman dapat digulir secara vertikal (scroll) ketika konten lebih panjang daripada ukuran layar. Lalu, menambahkan ActionButtonsWidget untuk menampilkan tombol aksi keuangan dan RecentTransactionsWidget untuk menampilkan daftar transaksi terakhir. SizedBox digunakan untuk memberikan jarak antar-komponen agar tampilan lebih rapi.

  2. Mengganti ukuran text saldo pada class BalanceCardWidget.

    Ukuran font text yang awalnya 24 diganti menjadi 28 untuk meningkatkan visibilitas teks.

  3. Menambahkan class ActionButtonsWidget sebagai widget tombol aksi.

    Class ActionButtonsWidget digunakan untuk menampilkan tiga pilihan aksi keuangan, yaitu Pemasukan, Pengeluaran, dan Transfer. Setiap tombol dibuat menggunakan fungsi _buildActionButton() sehingga tidak perlu menuliskan ulang struktur kode berkali-kali. Setiap fungsi menerima tiga parameter yaitu IconData icon untuk menentukan ikon, String label menentukan teks tombol, dan Color color untuk menentukan warna ikon dan background untuk mengatur tampilan setiap tombol.

  4. Menambahkan class RecentTransactionsWidget sebagai widget daftar transaksi terakhir.

    Menambahkan class RecentTransactionsWidget yang digunakan untuk menampilkan daftar transaksi terakhir. Widget menggunakan Column agar judul dan daftar transaksi disusun secara vertikal, widget diberi judul "Transaksi Terakhir". Card digunakan sebagai wadah untuk seluruh daftar transaksi agar setiap daftar transaksi memiliki bentuk panel dan efek bayangan.

    Di dalam Card digunakan Column untuk menyusun beberapa transaksi secara vertikal. Untuk setiap transaksi disusun menggunakan ListTile dengan beberapa bagian yaitu leading untuk ikon transaksi, title untuk nama transaksi, subtitle untuk tanggal transaksi, dan trailing untuk nominal transaksi.

  5. Output program.

D. Tugas

a) Tugas Modul 1

  1. Ubah warna tema BalanceCard dari biru (Colors.blueAccent) menjadi hijau emerald (Colors.teal).

    Card widget yang sebelumnya berwarna biru diganti menjadi warna teal, sehingga tampilan card saldo menjadi teal.

  2. Tambahkan teks statis berupa "No. Rekening: 1234-5678" di bagian bawah nominal saldo di dalam kartu.

    Menambahkan widget text untuk menampilkan informasi nomor rekening dibawah text nominal saldo.

  3. Output program.

b) Tugas Modul 2

  1. Pada widget Daftar Transaksi (ListTile), ubah warna trailing text pengeluaran menjadi merah dan text pemasukan menjadi hijau.

    Mengganti warna teks untuk setiap transaksi pengeluaran menjadi warna merah, sedangkan untuk setiap transaksi pemasukan menjadi warna hijau. Namun sebenarnya pada kode program awal sudah menerapkan hal ini.

  2. Tambahkan 2 transaksi fiktif baru ke dalam daftar "Transaksi Terakhir" di bawah kode yang sudah ada.

    Menambahkan 2 tambahan transaksi terakhir yaitu Bonus Performa sebagai pemasukan sebesar 1.500.000 dan Belanja Bulanan sebagai pengeluaran sebesar 500.000.

  3. Output program.

E. Kesimpulan

Berdasarkan praktikum yang telah dilakukan, dapat dipahami bahwa Flutter menggunakan konsep widget sebagai komponen dasar untuk membentuk struktur, tampilan, dan interaksi pada aplikasi. Praktikum ini menerapkan penggunaan StatelessWidget dan StatefulWidget, serta widget Row, Column, Padding, SizedBox, Container, Card, dan ListTile untuk mengatur tata letak dan tampilan aplikasi. Selain itu, manajemen state diterapkan pada kartu saldo sehingga nominal saldo dapat ditampilkan atau disembunyikan berdasarkan interaksi pengguna. Melalui praktikum ini juga diterapkan layouting dan styling pada aplikasi Expense Tracker, seperti deretan tombol aksi, daftar transaksi, perubahan warna kartu saldo, serta pembedaan warna transaksi pemasukan dan pengeluaran.
