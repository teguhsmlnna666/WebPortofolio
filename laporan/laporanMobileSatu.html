Laporan Praktikum - Form TextField dan TextFormField

Praktikum Aplikasi Mobile

A. Pendahuluan

Form merupakan widget yang digunakan untuk menerima berbagai jenis inputan seperti TextField, TextFormField, CheckBox, Switch, Dropwdown, dan lain-lain. Form menjadi media inputan yang dapat mengelola dan memvalidasi inputan tersebut. Pada praktikum ini kita menerapkan dua jenis form yaitu TextField dan TextFormField. TextField merupakan widget yang digunakan untuk menerima input teks dari pengguna, sedangkan TextFormField merupakan widget TextField yang lebih lengkap karena sudah terdapat logika validasi dan manajemen state didalamnya.

B. Tujuan

  1. Mampu memahami dan menerapkan beberapa input widgets.
  2. Mampu mengelola inputan dari berbagai input widgets.

C. Langkah Kerja Praktikum

a) Basic Form TextField

  1. Buat file dart baru dengan nama form-textfield.
  2. Import package flutter.

    Library ini berisikan berbagai jenis widget yang dapat digunakan.

  3. Tambahkan fungsi main().

    Fungsi main() ini digunakan untuk menjalankan program flutter.

  4. Tambahkan kelas MyApp.

    Kelas MyApp ini sebagai widget utama aplikasi yang mewarisi kelas StatelessWidget. StatelessWidget digunakan karena data yang akan ditampilkan tidak mengalami perubahan selama aplikasi berjalan. Didalamnya terdapat method build yang berisikan tampilan halaman aplikasi menggunakan Scaffold, didalamnya terdapat appBar dan body.

  5. Tambahkan kelas MyForm.

    Pada kelas MyForm kita menggunakan StatefulWidget yang digunakan ketika data yang akan ditampilkan dapat mengalami perubahan. Didalamnya terdapat method untuk membuat objek state yang akan menyimpan data dan logika MyForm, yaitu _MyFormState().

  6. Tambahkan kelas _MyFormState.

    Kelas ini berisikan data dan logika yang digunakan oleh MyForm, didalmnya terdapat:

    1. TextEditingController: digunakan untuk mengontrol dan mengambil isi dari TextField.
    2. Method dispose(): digunakan untuk membersihkan resource yang telah digunakan oleh controller.
    3. Method build(): digunakan untuk membuat tampilan dari MyForm yang berisikan semua komponen form.
    4. Padding: digunakan untuk memberikan jarak antara isi form dengan tepi layar, dengan ukuran 20 pixel.
    5. Column: digunakan untuk menyusun widget secara vertikal dari atas ke bawah dan isi kolom rata ke kiri.
    6. Text: widget yang digunakan untuk menampilkan tulisan, “Masukkan nama anda:”.
    7. Sizedbox: digunakan untuk memberikan jarak kosong antar widget, dengan jarak tinggi 10 pixel.
    8. Textfield: widget yang digunakan untuk menerima input teks dari pengguna. Diberikan beberapa dekorasi seperti labeltext (“Nama Lengkap”), hintText (“Misalnya Teguh”), border, dan prefixIcon (icon orang). Menghubungkan widget dengan TextEditingController melalui controller. Serta jenis keyboard yang digunakan dan fungsi onChanged untuk menampilkan informasi setiap perubahan pada debug console.
    9. ElevatedButton: digunakan untuk menampilkan tombol yang dapat ditekan oleh pengguna. Ketika tombol ditekan, nama yang sudah dimasukkan akan ditampilkan melalui SnackBar.
  7. Output program.

b) Basic Form TextFormField

  1. Buat file dart baru dengan nama form-textformfield.
  2. Import package flutter.
  3. Tambahkan fungsi main().
  4. Tambahkan kelas MyApp.

    Kelas MyApp ini sebagai widget utama aplikasi yang mewarisi kelas StatelessWidget. StatelessWidget digunakan karena data yang akan ditampilkan tidak mengalami perubahan selama aplikasi berjalan. Didalamnya terdapat method build yang berisikan tampilan halaman aplikasi menggunakan Scaffold, didalamnya terdapat appBar dan body.

  5. Tambahkan kelas MyFormText.

    Pada kelas MyFormText kita menggunakan StatefulWidget yang digunakan ketika data yang akan ditampilkan dapat mengalami perubahan. Didalamnya terdapat method untuk membuat objek state yang akan menyimpan data dan logika MyForm, yaitu _MyFormTextState().

  6. Tambahkan kelas _MyFormTextState.

    Kelas ini berisikan data dan logika yang digunakan oleh MyForm, didalmnya terdapat:

    1. _formKey: sebagai penghubung antara form dan proses validasi.
    2. Controller: digunakan untuk mengambil nilai yang diinput pengguna, yaitu nama dan email.
    3. Method dispose(): digunakan untuk membersihkan resource yang telah digunakan oleh controller.
    4. Fungsi _submitForm(): dijalankan ketika tombol Submit di klik pengguna, jika inputnya valid proses akan dilanjutkan dan menampilkan pesan berhasil, jika tidak proses berhenti dan muncul pesan error.
    5. TextFormField: widget untuk input teks yang dapat memvalidasi nilainya. Diberikan beberapa dekorasi seperti labeltext (“Nama Lengkap”), hintText (“Misalnya Teguh”), border, dan prefixIcon (icon orang). Menghubungkan widget dengan TextEditingController melalui controller. Serta jenis keyboard yang digunakan dan fungsi onChanged untuk menampilkan informasi setiap perubahan pada debug console.
    6. ElevatedButton: digunakan untuk menampilkan tombol yang dapat ditekan oleh pengguna. Ketika tombol ditekan, nama yang sudah dimasukkan akan ditampilkan melalui SnackBar.
  7. Output program.

D. Tugas Kelas B

  1. Buat file dart baru dengan nama main.
  2. Import package flutter.
  3. Tambahkan fungsi main.
  4. Tambahkan kelas MyApp.

    Berisikan method build yang digunakan untuk menentukan tampilan atau widget yang akan ditampilkan. Menggunakan MaterialApp sebagai struktur dasarnya dan mengarahkan ke UserRegistrationForm.

  5. Buat file dart baru dengan nama user_registration_form.
  6. Import package flutter.
  7. Tambahkan kelas UserRegistrationForm.

    Menggunakan kelas StatefulWidget sehingga data widget dapat berubah setelah dijalankan dan menghubungkannya ke state _UserRegistrationFormState.

  8. Tambahkan kelas _UserRegistrationFormState.

    Kelas ini akan menyimpan data dari aplikasi berupa form, controller, validasi, fungsi submit, dan tampilan. Disini menggunakan empat controller TextEditing yaitu name, email, password, dan confirmPassword.

  9. Tambahkan method dispose().

    Method ini digunakan untuk membersihkan resource yang telah digunakan oleh controller.

  10. Tambahkan fungsi untuk submitForm.

    Dijalankan ketika tombol Submit di klik pengguna, jika inputnya valid proses akan dilanjutkan dan menampilkan pesan berhasil, jika tidak proses berhenti dan muncul pesan error.

  11. Form input nama.

    Membuat widget form untuk inputan nama yang dihubungkan dengan controller _nameController. Form diberi dekorasi berupa label “Nama”, border, serta validasi input apakah sudah sesuai.

  12. Form input email.

    Membuat widget form untuk inputan email yang dihubungkan dengan controller _emailController. Form diberi dekorasi berupa label “email”, border, serta validasi input apakah sudah sesuai.

  13. Form input password.

    Membuat widget form untuk inputan password yang dihubungkan dengan controller _passwordController dan karakter password disembunyikan. Form diberi dekorasi berupa label “password”, border, serta validasi input apakah sudah sesuai.

  14. Form konfirmasi password.

    Membuat widget form untuk inputan password yang dihubungkan dengan controller _confirmPasswordController dan karakter password disembunyikan. Form diberi dekorasi berupa label “password”, border, serta validasi input apakah sudah sesuai dengan input password sebelumnya.

  15. Tambahkan ElevatedButton.

    Digunakan untuk membuat tombol Submit.

  16. Output Program.

E. Kesimpulan

Pada praktikum ini telah diterapkan dua jenis form yaitu TextField dan TextFormField untuk menerima input teks dari pengguna. TextField digunakan untuk menerima input teks dari pengguna, sedangkan TextFormField digunakan untuk input teks yang dapat memvalidasi nilainya. Selain itu, inputan dapat dikelola menggunakan TextEditingController dan proses validasi dapat dilakukan menggunakan Form. Pada tugas kelas B juga telah diterapkan form input nama, email, password, dan konfirmasi password dengan validasi input. Dengan demikian, praktikum ini membantu memahami dan menerapkan beberapa input widgets serta mengelola inputan dari berbagai input widgets.
